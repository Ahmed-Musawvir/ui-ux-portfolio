# 🎨 PalettePro

**PalettePro** is a modern and minimalist web application concept designed in **Figma** for color palette inspiration.  
It focuses on simplicity, creativity, and accessibility for designers, artists, and developers who work with color daily.

---

## 🧠 Overview
PalettePro allows users to:
- Explore colour palettes
- Save and organize favorite palettes.
- Copy HEX and RGB values easily.

---

## 🖌️ Design Goals
- Minimalist interface with focus on color display.  
- Soft, neutral backgrounds to emphasize palette tones.  
- Smooth component hierarchy for easy navigation.  
- Balance between function and aesthetics.  

---

## 🧩 Tools Used
- **Figma** for UI/UX Design  
- **Google Fonts** for typography styling  
- **Color Hunt & Coolors** as inspiration sources
